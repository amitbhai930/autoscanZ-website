# AutoScanZ 🔐

AutoScanZ is a full-stack web application that performs automated security scans
on domains or IP addresses to detect open network ports.

## 🚀 Features
- Port scanning for common services
- Real-time scan execution
- Scan history stored in MongoDB
- Clean dark/light UI
- Deployed on Render

## 🧱 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- Database: MongoDB Atlas
- Hosting: Render

## 🔍 How It Works
1. User submits a target domain/IP
2. Backend performs a port scan
3. Results are saved in MongoDB
4. User views results & scan history
